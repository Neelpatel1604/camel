## MemantoToolkit

```python
class MemantoToolkit(BaseToolkit):
```

A toolkit for explicit Memanto memory operations via function calling.
Requires a running [Memanto server](https://docs.memanto.ai) and an existing
agent. It activates a session on initialization and retries once with a new
session token after a `401` response.

**Parameters:**

- **agent_id** (str, optional): Memanto agent identifier. Falls back to
  `MEMANTO_AGENT_ID`.
- **base_url** (str, optional): Memanto server URL. Falls back to
  `MEMANTO_BASE_URL`, then `http://localhost:8000`.
- **timeout** (Optional[float], optional): Toolkit operation timeout.
